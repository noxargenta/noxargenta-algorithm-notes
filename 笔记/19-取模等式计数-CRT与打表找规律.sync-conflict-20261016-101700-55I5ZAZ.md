# 取模等式计数 — 中国剩余定理 + 打表找规律

来源：[Bobo_s_Lucky_Modulo.cpp](../competition/niukemanyschool7/Bobo_s_Lucky_Modulo.cpp) — 2025牛客多校第七场 L（Problem L. Bobo 的幸运取模）

## 问题模型

给定正整数 n，统计有序数对 (a, b)（1 ≤ a, b ≤ n）的个数，满足：

```
(a mod b) + 1 = a mod (b + 1)
```

## 核心思想

1. **打表找规律**：先暴力枚举小范围，打印每个 b 对应的合法 a，观察到——对每个固定的 b，合法 a 在模 `b(b+1)` 意义下是**一段连续区间 `[b², b²+b-1]`**，且最小合法 a 是 b²。
2. **中国剩余定理解释**：因为 gcd(b, b+1) = 1，条件可写成对同一余数 r 满足 `a ≡ r (mod b)` 与 `a ≡ r+1 (mod b+1)`，CRT 保证所有 r 的解在模 b(b+1) 下恰好构成连续 b 个值——这就是"区间规律"的根源。
3. **O(√n) 计数**：b > √n 时 b² > n，没有合法 a，只需枚举 b 到 √n，对每个 b 用整除（完整周期 + 尾部余数）统计区间内 a 的个数。

## 推导

设 r = a mod b（0 ≤ r ≤ b-1），则 a = kb + r。代入条件：

```
a mod (b+1) = (kb + r) mod (b+1) = (r - k) mod (b+1)
```

要求等于 r+1，即 `(r - k) ≡ r + 1 (mod b+1)`，化简得：

```
-k ≡ 1 (mod b+1)   =>   k ≡ -1 ≡ b (mod b+1)
```

所以 k = b + m(b+1)（m ≥ 0），于是：

```
a = kb + r = b² + m·b(b+1) + r，  0 ≤ r ≤ b-1
```

**结论**：对固定 b，合法 a 是 `[b², b²+b-1]` 每个值再整体加 `b(b+1)` 整数倍的并集，即：

```
合法 a ≡ b², b²+1, ..., b²+b-1   (mod b(b+1))
```

> **CRT 视角**：条件要求 `a mod b = r` 且 `a mod (b+1) = r+1`（同一 r）。由于 b 与 b+1 互质，对每个 r 这个同余方程组在模 b(b+1) 下有唯一解，且所有 r 的解合起来正好是连续 b 个值——所以打表看到的"连续区间"不是巧合，是 CRT 的直接结论。

**计数**：最小合法 a = b²，故只需枚举 `b*b <= n`。对每个 b 令 t = b(b+1)，把 n 写成 `n = cnt·t + s`：

- 模 t 的每个完整周期内恰好包含 b 个合法余数（b²..b²+b-1）→ 完整周期 cnt 个，贡献 `cnt·b`
- 尾部余数 s 若 ≥ b²，则 `[b², s]` 里还能贡献 `s - b² + 1` 个

## 打表找规律（暴力代码）

```cpp
void solve() {   // 打印每个 b 对应的合法 a，观察规律
    for (int b = 1; b <= 20; b++) {
        cout << "b = " << b << ": ";
        for (int a = 1; a <= 200; a++) {
            if ((a % b) + 1 == a % (b + 1)) cout << a << " ";
        }
        cout << endl;
    }
}
```

输出节选：

```
b=1: 1 3 5 7 9 11 ...         // 奇数，模 2 余 1
b=2: 4 5 10 11 16 17 ...      // 模 6 余 4,5
b=3: 9 10 11 21 22 23 ...     // 模 12 余 9,10,11
b=4: 16 17 18 19 36 37 ...    // 模 20 余 16..19
```

观察：对 b，合法 a 模 b(b+1) 落在连续区间 `[b², b²+b-1]`，且最小值为 b² → 据此写出 O(√n) 计数。

## 正解代码

```cpp
void solve() {
    ll n;
    cin >> n;
    ll ans = 0;
    for (ll b = 1; b * b <= n; b++) {   // 最小合法 a = b²，b > √n 时无解
        ll t = b * (b + 1);
        ll cnt = n / t;                  // 完整周期个数
        ans += cnt * b;                  // 每个完整周期贡献 b 个
        ll s = n % t;                    // 尾部余数
        if (s >= b * b) ans += s - b * b + 1;   // 尾部 [b², s] 内的 a
    }
    cout << ans << endl;
}
```

## 复杂度

- 时间 O(√n)：n ≤ 10¹² 时约 10⁶ 次循环
- 空间 O(1)

## 经典应用

| 问题 | 做法 |
|------|------|
| 满足 `(a mod b)+1 = a mod (b+1)` 的数对计数 | 打表找区间规律 + CRT 证明 + O(√n) 整除计数 |
| 带模的等式计数（两同余式联立） | 写成 `a ≡ r (mod b)`、`a ≡ r+1 (mod b+1)`，CRT 合并 |
| 满足某同余条件的数在 [1,n] 内个数 | 完整周期 + 尾部余数整除统计，模板化处理 |

## 注意事项

- **必须开 long long**：n 最大 10¹²，答案量级约 n·ln(√n) ≈ 1.4×10¹³，`b*b`、`b*(b+1)`、`cnt*b` 都会溢出 int
- 循环上界用 `b*b <= n`（√n），因为最小合法 a = b²，b 更大时区间起点已超出 n
- 尾部判断用 `s >= b*b`（含等号）：b² 本身是合法 a（对应 r = 0）
- 别对 a 暴力枚举——a 可到 10¹² 量级，只有 O(√n) 的做法可行

## 验证样例

- n = 5 → 5，五对为 (1,1) (3,1) (4,2) (5,1) (5,2)
- n = 17 → 20
