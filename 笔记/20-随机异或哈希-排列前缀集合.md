# 随机异或哈希：比较排列前缀集合

来源：[2026 CCPC 网络赛补题 · eHash.cpp](../competition/2026CCPCNET/补题/eHash.cpp)

给每个值分配一个固定的 64 位随机数，再把集合中所有值的随机数异或起来，就能用一个整数表示集合的“指纹”。**插入一个值只需一次异或，比较两个集合只需比较指纹。**

## 1. 适用条件

| 比较对象 | 能否直接使用 | 原因 |
| :--- | :---: | :--- |
| 集合、排列的前缀集合 | 可以 | 每个值最多出现一次，顺序不影响集合 |
| 序列是否完全相同 | 不可以 | 异或不保留顺序 |
| 含重复值的多重集合 | 不可以 | 相同值出现两次会抵消，只保留次数的奇偶性 |

以下算法假设三个序列都是 `1..n` 的排列；用于其他输入模型时，需要先确认每个值在单个序列中至多出现一次。

## 2. 核心写法

```cpp
using u64 = uint64_t;
mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());

vector<u64> weight(n + 1);
for (int x = 1; x <= n; ++x) weight[x] = rng();

u64 h = 0;
for (int i = 1; i <= n; ++i) {
    h ^= weight[a[i]];  // 加入“值”的权重，而不是“位置”的权重
}
```

- `mt19937_64` 生成 64 位伪随机数，每次调用 `rng()` 得到一个权重。
- 同一个值在所有序列中必须共用 `weight[x]`，不能各生成一套。
- 先生成权重，再重复使用；不能每次加入元素都重新调用 `rng()`。
- 用 `uint64_t` 保存哈希，避免把生成的无符号随机数存入 `long long`。

对于集合 `S`，定义：

```text
H(S) = 对所有 x ∈ S 的 weight[x] 做异或
```

异或满足交换律、结合律，因此 `{1, 2}` 和 `{2, 1}` 的指纹相同。相同集合一定得到相同指纹；不同集合也可能碰撞，所以指纹相同只是高概率相同。

## 3. 前缀如何 O(1) 更新

`pre[j]` 表示第 `j` 个排列当前前缀的指纹。长度从 `i - 1` 增加到 `i` 时，只加入一个新值：

```cpp
pre[j] ^= weight[a[j][i]];
```

例如 `[1, 3, 2]` 和 `[2, 1, 3]` 都得到 `weight[1] ^ weight[2] ^ weight[3]`。排列顺序不同，但前缀集合相同。

来源代码在每个位置检查三对前缀：

```cpp
if (pre[0] == pre[1] || pre[1] == pre[2] || pre[0] == pre[2]) {
    ++ans;
}
```

**同一个位置最多计数一次**：判断的是“至少有一对相同”，不是相同的配对数量。原代码的 `ans = 1` 配合输出 `ans - 1`，可直接整理成从 `0` 开始计数。

## 4. 完整整理版（C++17）

保持来源代码的输入输出方式：先读测试组数，每组读 `n` 和三个长度为 `n` 的排列。

```cpp
#include <bits/stdc++.h>
using namespace std;
using u64 = uint64_t;

mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());

void solve() {
    int n;
    cin >> n;

    array<vector<int>, 3> a;
    for (auto& row : a) {
        row.resize(n + 1);
        for (int i = 1; i <= n; ++i) cin >> row[i];
    }

    vector<u64> weight(n + 1);
    for (int x = 1; x <= n; ++x) weight[x] = rng();

    array<u64, 3> pre{};
    int ans = 0;
    for (int i = 1; i <= n; ++i) {
        for (int j = 0; j < 3; ++j) pre[j] ^= weight[a[j][i]];
        if (pre[0] == pre[1] || pre[1] == pre[2] || pre[0] == pre[2]) {
            ++ans;
        }
    }
    cout << ans << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;
    while (t--) solve();
    return 0;
}
```

| 项目 | 复杂度 |
| :--- | :--- |
| 生成权重、读入三个排列 | O(n) |
| 扫描所有前缀 | O(n)，每个位置三次更新、三次比较 |
| 总空间 | O(n)，保存排列与权重 |

整理版用 `vector` 替代原代码的 `ll b[n + 1]`，后者是变长数组，不属于标准 C++。以下模板采用标准 C++ 容器。

## 5. 碰撞概率与双哈希

如果将各个权重视为独立、均匀的 64 位随机数，对两个固定的不同集合，碰撞概率为 `2^-64`。每组扫描至多比较 `3n` 对，按并集界，误判概率至多为 `3n / 2^64`。

这是理想随机模型下的估计；`mt19937_64` 是伪随机生成器，实际实现仍是随机化算法，并非确定性证明。需要进一步降低风险时，可以维护两套权重和前缀指纹：

```cpp
vector<u64> w1(n + 1), w2(n + 1);
for (int x = 1; x <= n; ++x) {
    w1[x] = rng();
    w2[x] = rng();
}
array<u64, 3> h1{}, h2{};

// 扩展第 j 个排列的前缀
h1[j] ^= w1[a[j][i]];
h2[j] ^= w2[a[j][i]];

// 两个分量都相同才认为指纹相同
bool equal = h1[u] == h1[v] && h2[u] == h2[v];
```

在两套权重独立的理想模型下，固定一对不同集合的碰撞概率降为 `2^-128`。双哈希也不能修复重复值被异或抵消的问题。

## 6. 常见坑与扩展

1. **直接异或原值不是随机哈希。** `{1, 2}` 和 `{4, 7}` 都异或成 `3`，结构性碰撞很容易构造。
2. **重复值会抵消。** `[1, 1]` 和空序列都得到 `0`；即使长度相同，`[1, 1]` 和 `[2, 2]` 也无法区分。
3. **值域必须能作为下标。** 示例假设 `1 <= a[j][i] <= n`；值域大时先统一离散化，或用映射保存权重。
4. **每组要清空状态。** `pre{}` 在 `solve()` 内初始化，避免上一组的前缀残留。
5. **空前缀是否计数取决于题意。** 来源代码只扫描 `1..n`，不会统计长度为 `0` 的前缀。

| 扩展场景 | 写法与限制 |
| :--- | :--- |
| 集合插入、删除 | 都执行 `h ^= weight[x]`；插入前确认不存在，删除前确认存在 |
| 区间指纹 | `pref[r] ^ pref[l - 1]`；有重复值时表示奇偶状态，不是多重集合 |
| 比较多重集合 | 可改用随机权重求和，并按 `2^64` 取模；保留次数信息，仍存在碰撞 |

记忆要点：**按值赋权，共用权重，前缀异或；适用集合，不保留顺序和完整次数。**
