# C++ 标准库技巧（几何 / 数值 / 数论）

来源：左程云系列 + 个人整理 — C++ 竞赛高频标准库函数速查

## 一、计算几何神器

### 1. `std::complex<double>` — 用复数做 2D 计算几何

很多国家队选手的 2D 几何模板用 `std::complex` 写，它天然就是 2D 向量：

```cpp
#include <complex>
using Point = complex<double>;

Point A = {3, 2}, B = {-2, 3};
Point C = A + B;             // 向量加法
Point D = A * 2.0;           // 向量数乘

double len = abs(A);         // 模长 sqrt(x^2 + y^2)，等价于 hypot(x, y)
double angle = arg(A);       // 极角，等价于 atan2(y, x)
```

**点乘 / 叉乘一行搞定**：

```cpp
// conj(A) 是共轭复数 (x, -y)
double dot = (conj(A) * B).real();   // 向量点乘 A · B
double cross = (conj(A) * B).imag(); // 向量叉乘 A × B（判断顺逆时针）
```

**向量旋转（极度优雅）**：

```cpp
// 构造长度为 r，角度为 theta 的向量 (r * cosθ, r * sinθ)
Point P = polar(1.0, theta);
Point rotated = A * polar(1.0, PI / 2.0); // 将向量 A 逆时针旋转 90 度！
```

### 2. `hypot(x, y, z)` — 3D 距离（C++17）

C++17 扩展了 hypot，支持三维距离，不用手动写 `sqrt(x*x + y*y + z*z)` 防溢出：

```cpp
double dist3d = hypot(x, y, z);
```

### 3. `remainder(x, y)` — 角度归一化神器

把角度规范化到 `[-π, π]`，只要一行：

```cpp
double theta_norm = remainder(theta, 2 * M_PI);   // 规范到 [-PI, PI]
```

## 二、数值与边界处理

### 1. `std::clamp(val, low, high)`（C++17）

限制数值在区间内，比 `min(max(val, low), high)` 清晰很多：

```cpp
#include <algorithm>

double val = 1.5;
double safe_cos = clamp(val, -1.0, 1.0);   // 防止 acos 因浮点误差爆 NaN
double angle = acos(safe_cos);
```

### 2. `std::lerp(a, b, t)`（线性插值，C++20）

求线段上按比例 t 分割的点（`a + t(b-a)`），保证 t=1 时严格等于 b，消除浮点累积误差：

```cpp
#include <cmath>
double mid = lerp(x1, x2, 0.5);   // 精确求中点
```

### 3. `std::midpoint(a, b)`（安全求中点，C++20）

防止大整数相加溢出的中点：

```cpp
#include <numeric>
long long mid = midpoint(L, R);   // 等价于 L + (R - L) / 2，绝不爆 long long
```

## 三、数论与位运算

### 1. `std::gcd` 与 `std::lcm`（C++17）

`<numeric>` 头文件，不用自己写辗转相除法：

```cpp
#include <numeric>
long long g = gcd(a, b);
long long l = lcm(a, b);
```

### 2. 内置位运算（GCC 内建函数 / C++20 `<bit>`）

状态压缩（状压 DP）必备：

| 功能 | GCC 内建写法 | C++20 标准写法（`<bit>`） |
| :--- | :--- | :--- |
| 数二进制中 1 的个数 | `__builtin_popcountll(x)` | `std::popcount(x)` |
| 求最高位 1 前面有几个 0 | `__builtin_clzll(x)` | `std::countl_zero(x)` |
| 求最低位 1 后面有几个 0 | `__builtin_ctzll(x)` | `std::countr_zero(x)` |

## 建议首选掌握顺序

1. `atan2(y, x)` 与 `hypot(x, y)` — 几何基础
2. `std::clamp` — 防三角函数溢出爆 NaN
3. `std::gcd` / `std::lcm` — 数论高频
4. `std::complex<double>` — 做复杂多边形 / 旋转几何题非常爽

## 注意事项

- `std::complex` 的 `operator*` 是复数乘法（模相乘、角相加），做向量数乘时用 `A * 2.0`（实数），不是两个 Point 直接相乘
- `conj(A) * B` 中的 `conj` 使实部 = 点乘、虚部 = 叉乘，是 complex 几何的黄金组合
- `hypot` 会自动防止中间平方溢出；三维 `hypot(x,y,z)` 需要 C++17
- `lerp`/`midpoint` 需要 C++20 编译选项
- GCC 内建函数 `__builtin_*` 结尾 `ll` 表示 long long 版本，带 `u` 的无符号更安全
